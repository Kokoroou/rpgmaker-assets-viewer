RPG Maker VX Ace.rgss3a
How to use
  1. Click Open Folder and select the game's root folder.
  2. Browse folders in the sidebar, click any asset to preview it, then use the download button to save individual files.
  3. Drag the sidebar edge to resize it. Resize and theme preferences are saved automatically.

More questions? See the FAQ.

Want to read the game's dialogue, choices and switches? Open MakerLens Events.
