RPG Maker extractor FAQ

MakerLens Assets opens encrypted RPG Maker game files (2000, 2003, XP, VX, VX Ace, MV and MZ) in your browser so you can preview and download the images and audio inside. It works on released games, with no editor and no plugin. Your files never leave your device.

How to use

  1. Click Select Game Folder (or Open Folder) and pick the game's main folder, the one next to Game.exe. You can also drop it anywhere on the page.
  2. Browse the folders in the sidebar and click an asset to preview it. The download button in the preview saves that file.
  3. Use Filter to narrow by type, image size or audio length, and the Unique only switch (Duplicates row of the sidebar) to hide identical copies.
  4. Download ZIP in the toolbar saves every file shown in the folder at once.
  5. In Chrome or Edge, the Assets | Events switch in the header opens the same game in MakerLens Events to read its dialogue.

Opening a game

How do I extract .rpgmvp, .rpgmvo or .png_ files from RPG Maker MV / MZ?

Open the game’s root folder; MakerLens reads the key for you.

  1. Click Open Folder, or drop the folder on the page.
  2. Select the game's root folder: the one that contains www/ (MV) or data/ and img/ (MZ).
  3. MakerLens reads the encryption key from data/System.json and decrypts the files.
  4. Preview them, or download them.

It decrypts:

  • Images: .rpgmvp, .png_
  • Audio: .rpgmvo, .rpgmvm, .ogg_, .m4a_

How do I extract a .rgss3a, .rgss2a or .rgssad archive?

Select the archive file. The key comes from the archive, so nothing else is needed.

  • Click Select archive and choose the file.
  • Usual names: Game.rgss3a (VX Ace), Game.rgss2a (VX), Game.rgssad (XP).
  • Selecting the game folder works too; MakerLens finds the archive inside it.

Which folder do I select?

The game’s root folder, the one next to Game.exe. MakerLens finds each layout below.

  • RPG Maker 2000 / 2003: RPG_RT.ldb and RPG_RT.lmt at the root.
  • XP, VX and VX Ace, packed in an archive: a .rgssad, .rgss2a or .rgss3a file at the root.
  • MV: files in www/.
  • MZ: data/ and img/.

Why does it say it found no images or audio?

The folder you picked holds no image or audio.

  • It is usually a subfolder, such as data/ or js/, or a folder that is not a game.
  • The message names the folder you picked.
  • Select the one above it, the game’s root folder.
  • The game you already had open stays on screen.

Can I open a game without picking its folder?

Yes, with View another way on the start screen. It offers three options.

  • Archive: Game.rgss3a and the like, picked on its own.
  • Individual files: .png_, .ogg_, .rpgmvp, plain .png and so on.
  • Game link: it comes from the game itself (⚙ → Share → MakerLens link). Its token sits after the #, so no server receives it. Only https://*.workers.dev addresses are accepted.

Where is the encryption key? Do I need to enter it?

No. MakerLens reads it for you.

  • RPG Maker MV and MZ store the key as encryptionKey in data/System.json.
  • If images or audio fail to open, select the game's root folder, not a subfolder such as img/.

Is this an RPGM unpacker or decrypter?

Yes. It runs online in your browser, so there is nothing to download or install.

  • Shows RPG Maker 2000 / 2003 .xyz images.
  • Unpacks XP, VX and VX Ace archives (.rgssad, .rgss2a, .rgss3a).
  • Decrypts RPG Maker MV / MZ images and audio (.rpgmvp, .png_, .rpgmvo, .ogg_).
  • Extracts images and audio only. Other files in an archive, such as scripts and maps, are not shown.

Which RPG Maker versions are supported?

RPG Maker 2000 / 2003, XP, VX, VX Ace, MV and MZ.

  • 2000 / 2003 games are not encrypted: their .xyz images are shown and downloaded as PNG, next to their .png and .bmp.
  • Unencrypted .png, .jpg, .gif, .webp, .bmp, .ogg, .m4a, .mp3 and .wav files inside a game folder are shown as well.
  • .mid music (2000 / 2003, XP and VX) is listed for download, since browsers cannot play MIDI.

Browsing and downloading

Can it find duplicate files?

Yes, with the Unique only switch in the Duplicates row of the sidebar.

  • MakerLens compares the content of every file in your browser (a SHA-256 hash of the decrypted bytes).
  • It hides identical copies and marks each copied file with how many copies exist.
  • All copies are listed in a Duplicates folder in the sidebar.
  • With Unique only on, Download folder saves one file per content.

Can I filter by image size or audio length?

Yes, with the Filter button in the toolbar.

  1. Choose Images or Audio.
  2. Set a width and height range in pixels (or pick a preset such as 48×48 tiles or 576×288 face sheets), or a length range in seconds or m:ss.
  3. Each card shows its size or length, and Download folder saves only the files that pass the filter.

Privacy: MakerLens reads only the header of each file in the folder on screen, in your browser. Nothing is decoded or uploaded.

Can I see a character walk?

Yes. Open a character sheet and its walk cycle plays.

  • Sheets whose name starts with $ hold one character (3 × 4 frames).
  • Other sheets hold eight (12 × 8).
  • RPG Maker 2000 / 2003 CharSet images play too.

Can I browse files one-handed on a phone?

Yes. The preview is built for one hand.

  • Tap a file to open it.
  • Swipe left or right for the next or previous file; swipe down to close.
  • Pinch or double-tap to zoom; drag to move a zoomed image.
  • The phone’s Back button or back gesture closes the preview too.
  • Close, previous, next and download sit in one bar at the bottom, within reach of your thumb.

Can I download all files at once?

Yes, as one ZIP file.

  1. Open a folder in the sidebar.
  2. Press Download ZIP in the toolbar.

To save a single file, use the download button in its preview.

Privacy, install and legal

Are my game files uploaded anywhere?

No. Your files never leave your device.

  • Files are read and decrypted inside your browser; files, file names and keys stay on your device.
  • The page’s Content-Security-Policy blocks requests to any server except these two.
  • An anonymous counter, which receives only the page address, the referrer and the names of a few actions (such as how a game was opened or which feature was used, never what was opened).
  • The optional feedback form, which sends only the rating and comment you choose to send.

Details: Privacy & analytics.

Do I need to install anything? Does it work offline?

No. It needs no installation, and it works offline once the page has loaded.

  • It runs in modern desktop browsers such as Chrome, Edge and Firefox.
  • Opening, previewing and downloading work without an internet connection after the page has loaded.
  • You can also download the source code and open index.html locally.

Is it legal to extract RPG Maker game assets?

MakerLens is intended for personal use only, to access assets from games you own.

  • Redistributing extracted assets may violate the game’s license or copyright.
  • Check the game’s terms before reusing anything.

Can I read the game’s dialogue and events too?

Yes, with MakerLens Events, the other MakerLens tool.

  • In Chrome or Edge, once a game folder is open, the Assets | Events switch in the header carries the same folder to it without picking it again.
  • The folder stays on your device.
  • See the Events FAQ.
