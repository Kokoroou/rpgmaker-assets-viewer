RPG Maker extractor FAQ

MakerLens opens encrypted RPG Maker game files in your browser so you can preview and download the images and audio inside. Your files never leave your device.

How do I extract .rpgmvp, .rpgmvo or .png_ files from RPG Maker MV / MZ?

Click Open Folder and select the game's root folder — the one that contains www/ (MV) or data/ and img/ (MZ). MakerLens reads the encryption key from data/System.json automatically, then decrypts .rpgmvp / .png_ images and .rpgmvo / .rpgmvm / .ogg_ / .m4a_ audio so you can preview and download them.

How do I extract a .rgss3a, .rgss2a or .rgssad archive?

Click Select archive and choose the archive file, usually named Game.rgss3a (VX Ace), Game.rgss2a (VX) or Game.rgssad (XP). The key is derived from the archive itself, so nothing else is needed. Selecting the game folder also works; MakerLens finds the archive inside it.

Is this an RPGM unpacker or decrypter?

Yes. MakerLens decrypts RPG Maker MV / MZ images and audio (.rpgmvp, .png_, .rpgmvo, .ogg_) and unpacks XP, VX and VX Ace archives (.rgssad, .rgss2a, .rgss3a). It runs online in your browser, so there is nothing to download or install. It extracts images and audio only; other files in an archive, such as scripts and maps, are not shown.

Where is the encryption key? Do I need to enter it?

No. RPG Maker MV and MZ store the key as encryptionKey in data/System.json, and MakerLens reads it from there. If images or audio fail to open, make sure you selected the game's root folder, not a subfolder such as img/.

Are my game files uploaded anywhere?

No. Files are read and decrypted inside your browser; files, file names and keys never leave your device. The page's Content-Security-Policy blocks requests to any server except an anonymous page-view counter, which receives only the page address and referrer, and the optional feedback form, which sends only the rating and comment you choose to send. Can I download all files at once?

Yes. Open a folder in the sidebar and use the Download folder button to save every asset in it as a single ZIP file. Individual files can be downloaded from the preview.

Can it find duplicate files?

Yes. Press the Unique only button in the toolbar. MakerLens then compares the content of every file in your browser (a SHA-256 hash of the decrypted bytes), hides identical copies, marks each copied file with how many copies exist, and lists them all in a Duplicates folder in the sidebar. With Unique only on, Download folder saves one file per content.

Can I filter by image size or audio length?

Yes. Press the Filter button in the toolbar. Choose Images or Audio, set a width and height range in pixels (or pick a preset such as 48×48 tiles or 576×288 face sheets) and a length range in seconds or m:ss. MakerLens reads only the header of each file in the folder on screen, in your browser, to learn its size or length; nothing is decoded or uploaded. Each card then shows its size or length, and Download folder saves only the files that pass the filter.

Can I browse files one-handed on a phone?

Yes. Tap a file to open it, then swipe left or right on it for the next or previous file, swipe down to close, pinch or double-tap to zoom and drag to move a zoomed image. The phone's Back button or back gesture closes the preview too. Close, previous, next and download sit in one bar at the bottom of the screen, within reach of your thumb.

Which RPG Maker versions are supported?

RPG Maker MZ, MV, VX Ace, VX and XP. RPG Maker 2000 / 2003 are not supported. Unencrypted .png, .jpg, .gif, .webp, .bmp, .ogg and .m4a files inside a game folder are shown as well.

Do I need to install anything? Does it work offline?

No installation is needed: MakerLens runs in modern desktop browsers such as Chrome, Edge and Firefox. Once the page has loaded, opening, previewing and downloading work without an internet connection. You can also download the source code and open index.html locally.

Is it legal to extract RPG Maker game assets?

MakerLens is intended for personal use only, to access assets from games you own. Redistributing extracted assets may violate the game's license or copyright, so check the game's terms before reusing anything.
