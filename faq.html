RPG Maker extractor FAQ

MakerLens Assets opens encrypted RPG Maker game files (MV, MZ, VX Ace, VX, XP, 2000 and 2003) in your browser so you can preview and download the images and audio inside. It works on released games, with no editor and no plugin. Your files never leave your device.

How to use

  1. Click Select Game Folder (or Open Folder) and pick the game's main folder, the one next to Game.exe. You can also drop it anywhere on the page.
  2. Browse the folders in the sidebar and click an asset to preview it. The download button in the preview saves that file.
  3. Use Filter to narrow by type, image size or audio length, and Unique only to hide identical copies.
  4. Download ZIP in the toolbar saves every file shown in the folder at once.
  5. In Chrome or Edge, the Assets | Events switch in the header opens the same game in MakerLens Events to read its dialogue.

Opening a game

How do I extract .rpgmvp, .rpgmvo or .png_ files from RPG Maker MV / MZ?

Click Open Folder and select the game's root folder — the one that contains www/ (MV) or data/ and img/ (MZ). MakerLens reads the encryption key from data/System.json automatically, then decrypts .rpgmvp / .png_ images and .rpgmvo / .rpgmvm / .ogg_ / .m4a_ audio so you can preview and download them.

How do I extract a .rgss3a, .rgss2a or .rgssad archive?

Click Select archive and choose the archive file, usually named Game.rgss3a (VX Ace), Game.rgss2a (VX) or Game.rgssad (XP). The key is derived from the archive itself, so nothing else is needed. Selecting the game folder also works; MakerLens finds the archive inside it.

Which folder do I select?

Select the game’s root folder, the one next to Game.exe. MV games keep their files in www/, MZ games in data/ and img/, and games packed in an archive keep a .rgssad, .rgss2a or .rgss3a file at the root. MakerLens finds each of these. RPG Maker 2000 / 2003 games have RPG_RT.ldb and RPG_RT.lmt at the root.

Why does it say it found no images or audio?

The folder you picked holds no image or audio. It is usually a subfolder, such as data/ or js/, or a folder that is not a game. The message names the folder you picked; select the one above it, the game’s root folder. The game you already had open stays on screen.

Can I open a game without picking its folder?

Yes. View another way on the start screen offers three options: an archive (Game.rgss3a and the like) picked on its own, individual files (.png_, .ogg_, .rpgmvp, plain .png and so on), and a game link. A game link comes from the game itself (⚙ → Share → MakerLens link). Its token sits after the #, so no server receives it, and only https://*.workers.dev addresses are accepted.

Where is the encryption key? Do I need to enter it?

No. RPG Maker MV and MZ store the key as encryptionKey in data/System.json, and MakerLens reads it from there. If images or audio fail to open, make sure you selected the game's root folder, not a subfolder such as img/.

Is this an RPGM unpacker or decrypter?

Yes. MakerLens decrypts RPG Maker MV / MZ images and audio (.rpgmvp, .png_, .rpgmvo, .ogg_) unpacks XP, VX and VX Ace archives (.rgssad, .rgss2a, .rgss3a), and shows RPG Maker 2000 / 2003 .xyz images. It runs online in your browser, so there is nothing to download or install. It extracts images and audio only; other files in an archive, such as scripts and maps, are not shown.

Which RPG Maker versions are supported?

RPG Maker MZ, MV, VX Ace, VX, XP and 2000 / 2003. RPG Maker 2000 / 2003 games are not encrypted: their .xyz images are shown and downloaded as PNG, next to their .png and .bmp. Unencrypted .png, .jpg, .gif, .webp, .bmp, .ogg, .m4a, .mp3 and .wav files inside a game folder are shown as well; .mid music (2000 / 2003, XP and VX) is listed for download, since browsers cannot play MIDI.

Browsing and downloading

Can it find duplicate files?

Yes. Press the Unique only button in the toolbar. MakerLens then compares the content of every file in your browser (a SHA-256 hash of the decrypted bytes), hides identical copies, marks each copied file with how many copies exist, and lists them all in a Duplicates folder in the sidebar. With Unique only on, Download folder saves one file per content.

Can I filter by image size or audio length?

Yes. Press the Filter button in the toolbar. Choose Images or Audio, set a width and height range in pixels (or pick a preset such as 48×48 tiles or 576×288 face sheets) and a length range in seconds or m:ss. MakerLens reads only the header of each file in the folder on screen, in your browser, to learn its size or length; nothing is decoded or uploaded. Each card then shows its size or length, and Download folder saves only the files that pass the filter.

Can I see a character walk?

Yes. Open a character sheet and MakerLens plays its walk cycle. Sheets whose name starts with $ hold one character (3 × 4 frames); other sheets hold eight (12 × 8). RPG Maker 2000 / 2003 CharSet images play too.

Can I browse files one-handed on a phone?

Yes. Tap a file to open it, then swipe left or right on it for the next or previous file, swipe down to close, pinch or double-tap to zoom and drag to move a zoomed image. The phone's Back button or back gesture closes the preview too. Close, previous, next and download sit in one bar at the bottom of the screen, within reach of your thumb.

Can I download all files at once?

Yes. Open a folder in the sidebar and use the Download ZIP button in the toolbar to save every asset in it as a single ZIP file. Individual files can be downloaded from the preview.

Privacy, install and legal

Are my game files uploaded anywhere?

No. Files are read and decrypted inside your browser; files, file names and keys never leave your device. The page's Content-Security-Policy blocks requests to any server except an anonymous counter, which receives only the page address, the referrer and the names of a few actions (such as how a game was opened or which feature was used, never what was opened), and the optional feedback form, which sends only the rating and comment you choose to send. Details: Privacy & analytics.

Do I need to install anything? Does it work offline?

No installation is needed: MakerLens runs in modern desktop browsers such as Chrome, Edge and Firefox. Once the page has loaded, opening, previewing and downloading work without an internet connection. You can also download the source code and open index.html locally.

Is it legal to extract RPG Maker game assets?

MakerLens is intended for personal use only, to access assets from games you own. Redistributing extracted assets may violate the game's license or copyright, so check the game's terms before reusing anything.

Can I read the game’s dialogue and events too?

Yes, with MakerLens Events, the other MakerLens tool. In Chrome or Edge, once a game folder is open, the Assets | Events switch in the header carries the same folder to it without picking it again. The folder stays on your device. See the Events FAQ.
