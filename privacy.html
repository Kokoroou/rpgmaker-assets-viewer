Privacy

Your files never leave your device. Everything below explains how that works and what little we do count.

Your files

  • Game files are read and decrypted entirely inside your browser. No file, key or file name is ever sent to any server.
  • Try it: once the page has loaded, disconnect from the internet — opening, previewing and downloading still work.
  • A Content-Security-Policy tells your browser to block requests to any host except the page itself, the anonymous counter, the feedback form below and, only if you open a game link (see below), a workers.dev game site, so this is enforced by the browser, not just promised.

Game links

"View another way → Game link" opens a game that its owner published with rpgmaker-web-toolkit, using the read-only link the owner made inside the game (⚙ → Share → MakerLens link) (the game does not have to be public).

  • The link carries a key after the #, a part of the address that browsers never send to any server, so MakerLens never receives it. Your browser sends the key only to the game's own site, in a header, with no cookies, and the page forgets it when you close the tab.
  • The files travel from the game's site straight into your browser. Nothing goes through MakerLens, and nothing is written to the game: the tool stays read-only.
  • The usage count and feedback never include the link, the game's address or any file name.
  • The key only opens the game's data, pictures and audio, expires (24 hours unless the owner chose otherwise) and the owner can stop it at any time. It does not open the game's saves.

"Upload files to this site?"

When you pick a folder, some browsers (e.g. Chrome) show a prompt asking whether to upload files. That is the browser's standard wording for giving a page access to a folder — the files are only read locally. In Chrome and Edge we use a newer folder picker whose prompt says view files instead. Dragging the folder onto the page shows no prompt at all.

Anonymous usage count

To know how many people use the tools and how they find them, each page load on the MakerLens site (home page, MakerLens Assets and MakerLens Events) sends one request to GoatCounter containing:

  • the page path (e.g. /assets/ or /events/),
  • the referring site (e.g. Google), and
  • traffic-source link parameters such as utm_source=chatgpt.com.

Never sent: file or folder names, game titles, keys, file contents, or map, event and dialogue text. No cookies or local identifiers are used, and GoatCounter does not store IP addresses. Nothing is sent if your browser has Do Not Track or Global Privacy Control enabled, or if you open a local copy of the tool. If the request is blocked (ad blocker, firewall), the tool works exactly the same.

The code is short and public: js/analytics.js (Assets and home page) and js/analytics.js (Events).

Feedback (optional)

After you open a second game, a small card may ask you to rate MakerLens from 1 to 5 stars. Tapping a star sends that rating; you can then add a short comment, sent only if you press Enter or the send button. You can also send a bug report or idea at any time from About → Report a bug or idea. Nothing is sent unless you tap a star or press Send; closing or ignoring the card sends nothing.

MakerLens Events has the same card and form, with the same rules and the same fields listed below; it asks separately, after you open a second game in Events, and remembers its answer under its own key. Messages from each tool are kept apart so each can be rated on its own.

Each message is one request to our own feedback endpoint (a Cloudflare Worker) with:

  • the type (rating, bug or idea) and the star rating,
  • the comment you typed (up to 1000 characters),
  • your browser language (e.g. vi), so the comment can be read correctly,
  • for a comment added right after a star: a one-time reference to the star you just sent (kept only in the open tab, never in your browser storage), so the star and the comment are shown as one entry, and
  • roughly how many games you have opened (1, 2, 3-5, 6-10, 11+), and
  • for bug reports only, unless you remove it: your browser and system, e.g. Chrome 131 · Windows, shown in the form before sending (tap it to leave it out).

Never sent: file or folder names, game titles, the engine, keys or file contents. We store the date (without time) but no IP address, cookie or identifier, so a message cannot be linked to you. The only link is the one-time reference above, which joins a star to the comment you add to it right away; it names that entry, not you, and is not stored. Messages are kept with no end date: they are not deleted automatically. So please don't put personal or sensitive information in a comment (your name, email address, account names or anything else that identifies you). If you want a reply, open a GitHub issue instead. To have a comment you sent removed, open an issue quoting it.

The card is not shown if your browser has Do Not Track or Global Privacy Control enabled, or on local copies of the tool, and after you answer it never appears again. Whether it was shown, skipped or answered is also counted as an anonymous GoatCounter event (only that word, no content). Events does not count these events. Code that sends it: js/feedback.js (Assets) and js/feedback.js (Events). Only the developer can read the messages; the inbox is behind a login, and Worker request logs are turned off.

Preferences

The theme follows your system setting unless you change it. Your theme choice, sidebar layout and whether you already answered the feedback card in each tool (how many games you opened, whether you answered or chose "Not now") are stored in your browser's localStorage. This is not an identifier and never leaves your device; clearing site data resets it.

Hosting

The site is served by Cloudflare Workers at makerlens.kokoroou.workers.dev. The old address, kokoroou.github.io/rpgmaker-assets-viewer/, is served by GitHub Pages and keeps an older copy of MakerLens Assets with a link to the new address. Like any web host, Cloudflare and GitHub see your IP address and browser in order to deliver the pages, under their own privacy policies (Cloudflare, GitHub). That data is not passed on to us: request logs for the MakerLens Worker are turned off, and its only code picks which static page to return.

For a privacy question or request, such as removing a comment you sent, open a GitHub issue. Changes to this page are listed in its history on GitHub.
