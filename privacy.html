Privacy

Your files never leave your device. Everything below explains how that works and what little we do count.

Your files

  • Game files are read and decrypted entirely inside your browser. No file, key or file name is ever sent to any server.
  • Try it: once the page has loaded, disconnect from the internet — opening, previewing and downloading still work.
  • A Content-Security-Policy tells your browser to block requests to any host except the page itself and the anonymous counter below, so this is enforced by the browser, not just promised.

"Upload files to this site?"

When you pick a folder, some browsers (e.g. Chrome) show a prompt asking whether to upload files. That is the browser's standard wording for giving a page access to a folder — the files are only read locally. In Chrome and Edge we use a newer folder picker whose prompt says view files instead. Dragging the folder onto the page shows no prompt at all.

Anonymous usage count

To know how many people use the tool and how they find it, each page load sends one request to GoatCounter containing:

  • the page path (e.g. /rpgmaker-assets-viewer/),
  • the referring site (e.g. Google), and
  • traffic-source link parameters such as utm_source=chatgpt.com.

Never sent: file or folder names, game titles, keys or file contents. No cookies or local identifiers are used, and GoatCounter does not store IP addresses. Nothing is sent if your browser has Do Not Track or Global Privacy Control enabled, or if you open a local copy of the tool. If the request is blocked (ad blocker, firewall), the tool works exactly the same.

The code is short and public: js/analytics.js.

Preferences

Theme and sidebar layout are stored in your browser's localStorage for convenience. They never leave your device.
